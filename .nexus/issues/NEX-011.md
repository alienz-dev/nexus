## Description

Hono-based REST API server with routes for search, gaps, digest, and status.

## Acceptance Criteria

- [ ] GET /api/search?q=...&limit=...

- [ ] GET /api/digest?period=daily|weekly

- [ ] GET /health
- [ ] CORS enabled
- [ ] Request logging middleware

## Technical Notes

- Hono is lightweight and edge-ready
- Routes are modular (each in own file)
- Server entry point loads config and initializes all components
