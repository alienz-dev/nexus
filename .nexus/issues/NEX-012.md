## Description

Agent that compares the knowledge graph (skill entities) against job market demand to identify skill gaps.

## Acceptance Criteria

- [ ] Retrieves all skill entities from the store
- [ ] Searches job listings for each skill to measure demand
- [ ] Computes gap as (demand - current_level)
- [ ] Returns sorted list of SkillGap objects
- [ ] AgentResult with timing information

## Technical Notes

- Demand is normalized from search hit count (0-10 scale)
- Skills with demand > current level are flagged as gaps
