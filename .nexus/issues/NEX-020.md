## Description

RSSHub integration for generating RSS feeds from 1000+ sources that don't have native RSS.

## Acceptance Criteria

- [ ] RSSHub server connection (configurable URL)
- [ ] Route configuration for custom feeds
- [ ] Feed generation from RSSHub routes
- [ ] Error handling for unreachable RSSHub
- [ ] Integration with RssBridge adapter

## Technical Notes

- RSSHub is self-hosted (localhost:1200 default)
- Routes configured in nexus.yaml
- Phase 4 implementation
