## Description

Scaffold the nexus project with package.json, TypeScript config, vitest, gitignore, and configuration loading. Implement shared utilities (db, config, logger, hash) and CLI skeleton.

## Acceptance Criteria

- [ ] `npm install` succeeds
- [ ] `npm test` runs (even with stub tests)
- [ ] `npm run typecheck` passes
- [ ] `nexus --version` prints 0.1.0
- [ ] `nexus status` shows configured sources
- [ ] SQLite database initializes with WAL mode
- [ ] Config loads from nexus.yaml with defaults fallback

## Technical Notes

- Follow patterns from ai-feeds and job-hunter (Commander CLI, better-sqlite3, ESM)
- Use Zod for config validation
- SQLite WAL mode for concurrent read access
