## Description

Unified search across all sources using BM25 keyword matching, vector similarity, and graph traversal, combined with weighted Reciprocal Rank Fusion.

## Acceptance Criteria

- [ ] BM25 search on content_index table
- [ ] RRF merge function combining multiple result sets
- [ ] Configurable weights (bm25, vector, graph)
- [ ] Configurable RRF k parameter
- [ ] Returns SearchResult with score and source attribution

## Technical Notes

- Vector and graph search are placeholders for Phase 2
- RRF formula: sum of 1/(k + rank) for each result set
