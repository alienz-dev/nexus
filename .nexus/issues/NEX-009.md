## Description

Content indexer that uses MD5 hashing to skip unchanged content (Khoj pattern). Stores indexed content in SQLite for search.

## Acceptance Criteria

- [ ] content_index table with id, source, hash, title, content, url, timestamp, tags, entities
- [ ] Differential update: skip items whose content hash hasn't changed
- [ ] Returns counts: added, updated, skipped
- [ ] Composite primary key (id, source) for multi-source support
- [ ] MD5 hashing utility

## Technical Notes

- Hash only the content field (not metadata) for differential detection
- Transaction wrapping for batch inserts
