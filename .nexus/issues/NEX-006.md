## Description

Generic RSS/Atom feed reader that fetches from direct feed URLs and RSSHub endpoints.

## Acceptance Criteria

- [ ] Parses RSS 2.0 feeds (item, title, link, description, pubDate, category)
- [ ] Parses Atom feeds (entry, title, link[@href], content, summary, updated)
- [ ] Strips HTML from descriptions
- [ ] Handles fetch errors gracefully (skip unreachable feeds)
- [ ] Uses proper User-Agent header

## Technical Notes

- No external XML parser dependency — use regex-based extraction for simplicity
- 15-second timeout per feed
