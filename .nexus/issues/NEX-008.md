## Description

Structured storage for entities (skills, companies, roles), relations, and temporally-valid facts.

## Acceptance Criteria

- [ ] Entities table with type, name, properties (JSON), sources (JSON)
- [ ] Relations table with source_id, target_id, type, weight
- [ ] Facts table with entity_id, predicate, value, valid_from, valid_to, confidence
- [ ] Upsert operation for entities (insert or update by id)
- [ ] Query by type, get facts for entity (optionally only valid)

## Technical Notes

- Use WAL mode for concurrent reads
- JSON columns for flexible properties
- Indexes on type, name, source_id, target_id, entity_id
