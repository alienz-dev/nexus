## Description

Bridge adapter that reads articles from the ai-feeds SQLite database and normalizes them into FeedItem objects.

## Acceptance Criteria

- [ ] Reads from ai-feeds SQLite database (articles table)
- [ ] Normalizes rows to FeedItem interface
- [ ] Supports `since` parameter for incremental fetch
- [ ] Reports availability based on DB file existence
- [ ] Handles missing columns gracefully

## Technical Notes

- Use better-sqlite3 in readonly mode
- Map ai-feeds schema: id, title, summary/content, url, published_at, score, tags
