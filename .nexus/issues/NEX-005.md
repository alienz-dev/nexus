## Description

Bridge adapter that reads markdown files from the Obsidian vault with YAML frontmatter parsing.

## Acceptance Criteria

- [ ] Recursively walks vault directory for .md files
- [ ] Parses YAML frontmatter (title, tags, date, last-updated)
- [ ] Skips hidden directories and node_modules
- [ ] Supports `since` parameter (filter by mtime)
- [ ] Reports availability based on directory existence

## Technical Notes

- Use gray-matter for frontmatter parsing
- Content truncated to 5000 chars for indexing
- Relative path used as ID for stable references
